# Modelo OBJ para Gráficos por Computadora - Práctica 2

`columna.obj` es una columna rectangular cerrada creada para demostrar
traslación, rotación, escalamiento, inclinación, doblado, torsión y afilado.

- Dimensiones: 1.2 × 3 × 0.9 unidades arbitrarias.
- Vértices: 1 058.
- Triángulos: 2 112.
- Aristas: 3 168; característica de Euler: 2.
- Volumen original: 3.24 unidades cúbicas.
- Tamaño: 59 784 bytes. Sin materiales ni texturas.
- Cada arista pertenece a dos triángulos.

La versión usada para los experimentos está fijada al commit
`d9e9d3950824d88d922023f694954df790c85c6f`.

La inclinación constante es una transformación lineal y afín.
Las deformaciones son operaciones geométricas sobre la malla;
no constituyen una simulación física de materiales.
